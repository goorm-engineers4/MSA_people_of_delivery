# 🛡️ AI 메뉴 랭킹 시스템 - 가드레일 및 모델카드

## 🔒 가드레일 (Guardrails)

### 1. PII (개인정보) 보호
- **수집 데이터**: 사용자 ID, 선호도, 도시 정보만 수집
- **익명화 처리**: 사용자 ID는 해시 처리 후 저장
- **데이터 보관**: 개인 식별 정보는 30일 후 자동 삭제
- **로그 관리**: 개인정보가 포함된 로그는 즉시 마스킹 처리

```python
# PII 마스킹 예시
def mask_user_data(user_id, preference):
    masked_id = hashlib.sha256(str(user_id).encode()).hexdigest()[:8]
    return f"user_{masked_id}", preference
```

### 2. 금지어 필터링
- **부적절한 메뉴명**: 자동 필터링 및 관리자 알림
- **사용자 입력 검증**: 선호도 입력 시 허용 목록 기반 검증
- **AI 응답 검토**: 생성된 추천 결과에 대한 자동 검증

```python
FORBIDDEN_KEYWORDS = ['술', '담배', '도박', '불법', '혐오']
ALLOWED_PREFERENCES = ['매운', '달콤', '고기', '해산물', '채소', '구수한', '시원한']

def validate_input(preference):
    return preference in ALLOWED_PREFERENCES
```

### 3. 접근 권한 관리
- **API 키 인증**: 모든 요청에 대한 API 키 검증
- **Rate Limiting**: 사용자당 분당 10회 요청 제한
- **관리자 전용**: 성능 지표 및 로그는 관리자만 접근 가능
- **감사 로그**: 모든 API 호출에 대한 상세 로그 기록

```yaml
# Rate Limiting 설정
rate_limit:
  requests_per_minute: 10
  burst_limit: 20
  block_duration: 300  # 5분
```

### 4. 데이터 품질 보장
- **입력 검증**: 도시명, 선호도 유효성 검사
- **결과 검증**: NDCG@5 점수가 0.3 미만인 경우 알림
- **오류 처리**: 외부 API 실패 시 기본값으로 대체
- **모니터링**: 실시간 성능 지표 추적

### 5. 시스템 안정성
- **Fallback 메커니즘**: 날씨 API 실패 시 기본 날씨 사용
- **Circuit Breaker**: 연속 실패 시 자동 차단
- **Health Check**: 주요 컴포넌트 상태 모니터링
- **Graceful Degradation**: 부분 실패 시에도 기본 랭킹 제공

## 📋 미니 모델카드

| **항목** | **내용**                          |
|----------|---------------------------------|
| **모델명** | AI 메뉴 랭킹 시스템 v1.0               |
| **목적** | 날씨와 선호도 기반 메뉴 랭킹 및 NDCG@5 성능 측정 |
| **버전** | v1.0.0 (실시간 날씨 API 연동)          |

### 📥 입력 (Input)
- **필수**: `city` (도시명), `preference` (사용자 선호도)
- **선택**: `userId` (사용자 ID)
- **형식**: JSON POST 요청
- **예시**: `{"city": "서울", "preference": "매운"}`

### 📤 출력 (Output)
- **랭킹된 메뉴 리스트**: 상위 5-10개 메뉴
- **성능 지표**: NDCG@5 점수 (0.0-1.0)
- **메타데이터**: 실제 날씨, 온도, 총 메뉴 수
- **형식**: JSON 응답

### ⚙️ 알고리즘
- **랭킹 방식**: 가중치 기반 점수 계산
- **가중치**: 날씨(40%) + 선호도(30%) + 온도(30%)
- **성능 측정**: NDCG@5 (Normalized Discounted Cumulative Gain)
- **외부 API**: OpenWeatherMap API 연동

### 📊 성능 지표 (현재 상태)
- **평균 NDCG@5**: 측정불가 (Ground Truth 데이터 부족)
- **Hit@5**: 측정불가 (사용자 선호도 레이블 부족)
- **응답 시간 p95**: 87ms (실측)
- **시스템 가용성**: 99.9% (인프라 기준)

### 🎯 사용 사례
1. **메뉴 추천**: 날씨에 맞는 메뉴 추천
2. **성능 평가**: 추천 시스템 품질 측정
3. **A/B 테스트**: 랭킹 알고리즘 개선 효과 측정

### 🚫 한계 및 제약사항 (현재 MVP 단계)
- **데이터 부족**: 실제 사용자 선호도 및 주문 패턴 데이터 부족
- **성능 미검증**: NDCG@5 등 핵심 지표 측정 불가
- **Ground Truth 부재**: 사용자 만족도 레이블링 데이터 없음
- **메뉴 제한**: 샘플 메뉴 데이터 기반 (실제 메뉴 DB 연동 필요)
- **날씨 의존성**: OpenWeatherMap API 장애 시 성능 저하
- **선호도 단순화**: 단일 키워드 기반 (복합 선호도 미지원)

### 🔄 학습 데이터
- **메뉴 데이터**: 18개 샘플 메뉴 (한식, 양식, 중식 등)

- **사용자 데이터**: 익명화된 선호도 정보
- **평가 데이터**: 3개 시나리오 기반 성능 측정

### 🔧 유지보수

- **업데이트**: 월 1회 메뉴 데이터 갱신
